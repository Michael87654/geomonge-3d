# Бесплатное онлайн-распознавание через Cloudflare

Этот вариант запускает облачную модель Cloudflare Workers AI вместо Ollama. Сайт остаётся на GitHub Pages. Телефону нужен интернет только для ИИ; решатель и 2D/3D работают оффлайн. Текст задания передаётся Cloudflare. Исходники сервера не требуется публиковать в открытом GitHub-репозитории.

В качестве модели выбран `@cf/meta/llama-3.3-70b-instruct-fp8-fast`: он поддерживает JSON Mode. Схема намерений и системный текст те же, что у локального интерпретатора. Модель распознаёт цель, а геометрический решатель в браузере проверяет и строит результат. Ошибки распознавания возможны, поэтому следует проверять предпросмотр.

## Бесплатный план

По документации Cloudflare на 31.10.2026 Workers AI предоставляет 10 000 Neurons в день на плане Free. Это единицы вычислений, не число заданий. На Free превышение квоты приводит к ошибке, а не к автоматическому переходу на платный план. Платный план для этого проекта включать не нужно. Ошибка квоты отображается в приложении, обычные построения остаются доступны. Модель может временно быть занята.

## Сборка и публикация

```sh
node scripts/build-cloudflare-worker.mjs
cd cloudflare
npx wrangler deploy --dry-run
npx wrangler login
npx wrangler deploy
```

Сборка создаёт один файл `cloudflare/worker.mjs`, готовый также для редактора Cloudflare. `wrangler.jsonc` подключает AI binding `AI` и задаёт единственный разрешённый Origin GitHub Pages. Домен `workers.dev` предоставляет Cloudflare. API-ключ не помещается в интерфейс: сервер использует binding своего аккаунта. Доступ Wrangler можно отозвать в настройках Cloudflare.

После публикации проверить HTTPS-адрес `/health` и `/api/ollama/models`. Имена путей сохранены для совместимости с существующим клиентом; модель при этом выполняется в Cloudflare. `/health` проверяет binding, а фактическое распознавание проверяется отдельным POST-запросом.

В `public/app-config.json` указать `aiBaseUrl` полученного Worker, выполнить `npm run build` и опубликовать весь новый `dist`. Пользователю установленной PWA нужно принять обновление через «Инструменты → Установка и оффлайн». При включённой сети появится модель в разделе подключения.

Предусмотрены CORS, проверка входного текста, ограничение 70 КБ и 12 заданий, до 16 000 символов, одна фиксированная модель и ограничитель 10 запросов в минуту на экземпляр Worker. CORS не является авторизацией, ограничитель не является глобальным: жёсткий бесплатный потолок задаёт дневная квота провайдера. Тексты задач код не записывает в логи.
