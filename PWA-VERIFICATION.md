# Проверки PWA — 31 октября 2026

- TypeScript: проверка без ошибок.
- Vitest: **223 теста, 23 файла**, все прошли. Включены геометрия, парсер, символические алгоритмы, альтернативы, настройки, конфигурация ИИ и CORS/preflight сервера.
- Финальная production-сборка Vite и генерация service worker успешны; кэшируются 11 локальных ресурсов, включая Three.js. Внешних CDN для основной работы нет.
- Headless Microsoft Edge, эмуляция мобильного экрана: 320×640, 390×844, 844×390. Горизонтального переполнения документа нет; панели помещаются. Скриншоты просмотрены.
- Приложение открыто на `/geomonge-3d/`, service worker контролирует эту подпапку. Проверены manifest, scope, standalone и иконки. Chromium не сообщил ошибок устанавливаемости, кроме `in-incognito`: автоматический тест использует изолированный контекст. Сам факт установки этим тестом не проверен.
- После заполнения кэша отключена сеть, первая вкладка закрыта, новая вкладка открыла приложение с того же адреса. Работают SVG-эпюр, WebGL canvas 3D, сохранение набора настроек и SVG-экспорт.
- В эмуляции отправлен жест двумя пальцами в 2D. Ручное удобство жестов и скорость 3D на настоящем телефоне требуют отдельной проверки.
- Без сети кнопка ИИ отключена, показана причина; обычный решатель доступен. После возврата сети подключён отдельный тестовый API с CORS, выполнено распознавание записанного ответа модели и показаны три альтернативы. Это проверка транспорта/UI на имитации сервера, а не запуск облачной модели.
- Версия кэша изменена с QA-1 на QA-2, worker загружен в ожидание, нажата кнопка обновления. Приложение перезапущено на версии 2; наборы настроек сохранены. Старый кэш этого приложения удалён, посторонний кэш оставлен. Повторный оффлайн-запуск использовал версию 2.
- Ошибок JavaScript в сценарии PWA нет.

Не выполнены: установка/удаление через настоящий Android Chrome, запуск ярлыка в авиарежиме на физическом устройстве, проверка производительности конкретного телефона, сборка Docker (Docker в этой проверке не использовался), развёртывание и проверка внешнего сервера ИИ. Сервер подготовлен по выбору пользователя; его URL пока пустой.

GitHub Pages опубликован: https://michael87654.github.io/geomonge-3d/ . Workflow `pages build and deployment` №41231789042 завершён успешно. На HTTPS-адресе проверены HTTP 200, заполнение кэша, отсутствие потерянных ресурсов и ошибок JavaScript, сообщение о неподключённом сервере ИИ. В обычном изолированном профиле Edge API Chromium сообщил пустой список ошибок устанавливаемости. После отключения сети и закрытия первой вкладки приложение успешно открыто в новой вкладке из кэша; показано сообщение об отсутствии сети для ИИ. Установка ярлыка на телефон этим не проверена.

Настоящий первый запуск без интернета до загрузки ресурсов невозможен; браузер также может удалить кэш при очистке данных/нехватке места.
