# GeoMonge 3D

Сайт: https://michael87654.github.io/geomonge-3d/

Готовая PWA-сборка: геометрия, 2D/3D и экспорт работают оффлайн после первой загрузки. ИИ требует подключения к серверу; сервер пока не развёрнут.

[Установка и сервер ИИ](DEPLOYMENT.md) · [Проверки](PWA-VERIFICATION.md)

В корне опубликована готовая сборка; исходники, тесты и сервер переданы владельцу отдельным архивом GeoMonge-3D-PWA.zip. Для обновления распакуйте исходники, выполните `npm ci`, `npm test`, `npm run build`, затем загрузите новый dist с сохранением папки assets. Публикация GitHub Pages: main / (root).
